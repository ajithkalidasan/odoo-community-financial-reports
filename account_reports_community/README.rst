============================
Accounting Reports (Community)
============================

Trial Balance, General Ledger and other financial reports built on Odoo
Community's own ``account.report`` / ``account.report.line`` /
``account.report.expression`` engine.

This module does **not** depend on, include, or reuse any code from the
proprietary Odoo Enterprise ``account_reports`` module. It is a from-scratch
implementation intended for Odoo Community users.

Reports included
=================

* Trial Balance
* General Ledger
* Balance Sheet
* Profit and Loss
* Partner Ledger
* Aged Receivable
* Aged Payable
* Tax Report
* Journal Report
* Cash Flow Statement

Each report can be viewed on screen, printed to PDF and exported to XLSX.

Installation
=============

Depends only on the standard ``account`` module. Install like any other
Odoo addon.

Usage
=====

After installation, the reports are available under
**Accounting > Reporting**.
