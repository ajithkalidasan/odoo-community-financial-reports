Accounting Reports (Community)

Trial Balance, General Ledger and more — built entirely on Odoo Community

This module adds a computation layer, frontend and report content on top of the account.report / account.report.line / account.report.expression engine that already ships with Odoo Community. It brings the classic accounting reports back to Community edition:

  • Trial Balance
  • General Ledger
  • Balance Sheet
  • Profit and Loss
  • Partner Ledger
  • Aged Receivable / Aged Payable
  • Tax Report
  • Journal Report
  • Cash Flow Statement

Reports can be viewed on screen, exported to PDF and exported to XLSX.

Important: this module does not depend on, include, or reuse any code from the proprietary Odoo Enterprise account_reports module. It is a from-scratch, LGPL-3 licensed implementation on top of Community's own reporting engine, intended for Odoo Community users who need standard financial reports without an Enterprise subscription.
